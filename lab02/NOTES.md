Коммит 1:
Рабочая папка - это то место на вашем компьютере, где вы прямо сейчас работаете с файлами проекта. 
Вы можете добавлять новые документы, удалять старые или менять текст.

Индекс - черновик, ожидающий отправки, который необходимо будет отправить для работы далее.

коммит - сохраненное изменение, отправляется в историю проекта, версия к которой можно вернуться в любой момент

коммит 2:
git - версия прооекта, его сохраненные состояния, между которыми можно переключаться

github - облачное хранилище в интернете для передачи файлов git, для совместной работы

коммит 3:
git status — показывает текущее состояние рабочей папки и индекса
git diff — показывает разницу между вашей рабочей папкой и индексом
git diff --staged — показывает разницу между индексом и последним коммитом
